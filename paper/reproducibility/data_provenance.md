# Data Provenance

Document for each task:

- original dataset and authoritative URL;
- license and redistribution constraints;
- local transformation and filtering;
- train/validation/test sizes and class distributions;
- split seed and split files;
- document-, author-, or source-level overlap checks;
- annotation source and quality control;
- whether examples or labels were generated by an external model.

This file must be completed before the first external draft is circulated.
