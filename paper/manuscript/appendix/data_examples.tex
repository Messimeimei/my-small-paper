\section{Paired CoT and Label-Only Examples}
\label{app:dataset-examples}

For every evaluation type, we construct matched CoT and label-only views from
the same underlying instance. The two views preserve the task query, criteria,
scoring rubric, instance identifier, and gold label; they differ only in the
system instruction and required output format. The CoT view requests a
free-text rationale followed by the score, whereas the label-only view requests
only the score. Table~\ref{tab:evaluation-prompt-index} links to both views for
all seven evaluation types.
