\subsection{Local Training and Inference}

% 在每个模型规模内，所有方法使用相同的 Qwen3 backbone、LoRA 配置和固定划分。
% Qwen chat template 在训练和评测时均关闭，内置 thinking mode；RF rationale 
% 仅由显式 RF system prompt 触发。
Within each model scale, all methods use the same Qwen3 backbone, LoRA
configuration, and fixed data splits. Training and evaluation
render prompts with the Qwen chat template while disabling its built-in
thinking mode (\texttt{enable\_thinking=false}); RF rationales are elicited
only by the explicit RF system prompt.

% LoRA 应用于所有线性层，r=16、alpha=32、dropout=0.05、bias=none。
% 所有方法使用学习率 1e-4、余弦衰减、0.03 warm-up、3 epochs、
% 最大梯度范数 0.3、8 步梯度累积、BF16、SDPA 和 gradient checkpointing。
LoRA is applied to all linear layers with rank \(r=16\), scaling factor
\(\alpha=32\), dropout 0.05, and \texttt{bias=none}. All methods use a
learning rate of \(1\!\times\!10^{-4}\), cosine decay, a 0.03 warm-up ratio,
three epochs, a maximum gradient norm of 0.3, eight gradient-accumulation
steps, BF16 precision, SDPA attention, and gradient checkpointing with
\texttt{use\_reentrant=False}.
% 每个 epoch 后进行验证并保存 checkpoint，最终评测统一使用保存的最后一个 checkpoint。
% 本地推理采用 bfloat16 精度的 vLLM，并使用确定性贪心解码，
% 其中 \texttt{temperature=0}、\texttt{top\_p=1}。
Validation and checkpoint saving occur after each epoch, and final evaluation
consistently uses the last checkpoint. Local inference
uses bfloat16 vLLM and deterministic
greedy decoding with \texttt{temperature=0} and \texttt{top\_p=1}.

% SO 只监督最终分数；RS 和 ReaSon 监督 rationale 与分数。
% PaIR-BP、PaIR 和 RePaIR 为每个源样本构造配对的 DS 分数序列与
% RF rationale--score 序列。任务 user prompt 在所有方法间共享。
The supervision format differs by method. SO supervises only the final score,
whereas RS and ReaSon supervise a rationale followed by the score. PaIR-BP,
PaIR, and RePaIR construct paired sequences for every source example: a
score-only DS branch and a rationale-and-score RF branch. The corresponding
system and completion formats are shown in Figure~\ref{fig:scirm-evaluation};
task-specific user prompts are shared across methods and indexed in
Table~\ref{tab:prompt-map}.

% SO、RS 和 ReaSon 的每设备训练和评测 batch 均为 2。PaIR 系列的源样本
% batch 为 1，由 collator 展开成 DS/RF 两条序列；评测 batch 仍为 2。
SO, RS, and ReaSon use standard SFT with per-device training and evaluation
batch sizes of 2. PaIR-BP, PaIR, and RePaIR use a per-device source-example
batch size of 1; the paired-view collator expands each source row into one DS
and one RF sequence. Evaluation batch size remains 2.

% PaIR 分别在 DS 与 RF completion 的监督 token 上计算均值，再以 0.5/0.5
% 聚合。PaIR-BP 则把两个视图的监督 token 放在同一分母下平均。
For PaIR and RePaIR, \(\mathcal{L}_D\) and \(\mathcal{L}_R\) are averaged
over the supervised tokens of the DS and RF completions, respectively, and
combined as
\[
\mathcal{L}_{\mathrm{PaIR}}
=0.5\mathcal{L}_D+0.5\mathcal{L}_R.
\]
PaIR-BP retains the same paired examples but pools both views under one token
denominator:
\[
\mathcal{L}_{\mathrm{PaIR\text{-}BP}}
=\frac{M_D\mathcal{L}_D+M_R\mathcal{L}_R}{M_D+M_R},
\]
where \(M_D\) and \(M_R\) are the supervised-token counts of the two views.

% 所有方法的最大模型序列长度为 8192。generation validation 中，SO 使用
% batch 16 和 32-token 上限，其余方法使用 batch 8 和 512-token 上限。
% 最终评测对每个方法都运行 DS（最多 32 tokens）和 RF（最多 512 tokens）。
All methods use a maximum model sequence length of 8192. For generation-based
validation, SO uses a batch size of 16 and a 32-token generation limit; RS,
ReaSon, PaIR-BP, PaIR, and RePaIR use a batch size of 8 and a 512-token limit.
The ReaSon configuration omits \texttt{max\_new\_tokens} and therefore uses the
strategy default of 512. At final evaluation, every method is run under both
interfaces, with at most 32 generated tokens for DS and 512 for RF.

\subsection{Score Extraction and Metric Denominators}
\label{app:score-extraction}

% 严格解析只读取最后一个 <score> block，并要求其中整数属于任务合法分值集合。
% relaxed extraction 先保留严格结果；无 tag 时，再接受完整输出整数，或首/末
% 非空行中的合法裸整数或显式 score 表达。无法恢复的输出保持 invalid。
Strict parsing reads only the final \texttt{<score>} block and accepts it only
when its integer belongs to the task's legal score set. Relaxed extraction
retains a valid strict score; when no score tag is present, it additionally
accepts a legal whole-output integer -or a legal bare integer or explicit score
statement on the first or last nonempty line. Outputs that still cannot be
recovered remain invalid.

% Accuracy 和 Macro-F1 保留完整测试集并将 invalid 计为错误；Pearson、MAE
% 和 QWK 仅在每个 task--seed 条件下基于合法提取的预测计算，因此其分母为
% 该条件的 valid prediction 数。表~\ref{tab:full-method-task-level}报告两种
% 模型规模在 DS 和 RF 推理下采用严格解析得到的逐任务主要结果。
% 表~\ref{tab:full-method-averages}则对同一批 Qwen3-4B 输出采用宽松解析
% 重新计算汇总指标，作为解析敏感性分析；模型未重新运行。
Accuracy and Macro-F1 retain the full test-set denominator and count invalid
outputs as errors. Pearson, MAE, and QWK use only legally extracted predictions
within each task--seed condition, so their denominator is that condition's
valid-prediction count. Table~\ref{tab:full-method-task-level} and~\ref{tab:full-so-rs-secondary-merged}
reports task-level primary results under strict parsing for both model scales under
DS and RF inference. Table~\ref{tab:full-method-task-level-relaxed} recomputes aggregate
metrics from the same Qwen3-4B outputs under relaxed parsing as a parsing
sensitivity analysis; no model is rerun.
