# Submission Snapshots

Do not edit the manuscript here. For each submitted version, create a directory
such as `arr-2026-10-12/` containing the anonymous PDF, supplementary archive,
metadata checklist, and checksums. PDF and ZIP files are ignored by Git because
they can contain private submission metadata.

Only create a submission snapshot after the locally compiled PDF has passed
anonymity, page-limit, font-embedding, citation, Limitations, and ethics checks.
