# 研究与写作文档

本目录存放论文规划与写作指导；它与 `manuscript/`、`analysis/`、
`literature/`、`reproducibility/` 和 `submission/` 共同组成
`paper_workspace/`。项目代码、数据和实验输出保留在上一级项目目录。

## 建议阅读顺序

1. [论文逐节文献、表达与图表蓝图](SECTION_LITERATURE_FIGURE_BLUEPRINT.md)：逐节参考论文、段落功能、可用表达、图表设计和证据边界。
2. [完整写作与投稿指南](PAPER_WRITING_AND_SUBMISSION_GUIDE.md)：当前论文主线、章节写法、机制分析、实验优先级和投稿流程。
3. [当前研究分析](RESEARCH_ANALYSIS.md)：已有结果的论文定位、可支持结论和候选机制解释。
4. [科学写作评价与思维链文献综述](科学写作评价与思维链文献综述.md)：相关研究脉络、正反证据与研究空白。
5. [毕业与投稿 Venue 指南](GRADUATION_VENUE_GUIDE.md)：投稿路线、毕业认定风险和需要向学院确认的事项。
