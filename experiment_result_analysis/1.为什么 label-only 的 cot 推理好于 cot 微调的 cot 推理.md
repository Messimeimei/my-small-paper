## 实验现象

一共两套训练数据，所有的提示词都是一样的，只有在 system prompt 部分，label-only 明确要求只输出 <score></score> 标签；而 cot 的训练数据明确要求同时输出
<reasoning></reasoning> 和 <score></score> 标签。然后在训练环节，都是用的标准的 sft + lora 方法，lora 配置一样，只有计算 loss 的时候，

前者只计算：
```
<score>5</score>
```
的损失；

而后者计算：
```
<reasoning>
这条评论提到了 Figure 9，并明确指出单位不同的变量被放入同一个函数……
因此它既具体又有依据。
</reasoning>
<score>5</score>
```

而一般的 sft + Lora 训练方法，在计算损失的时候，是对每个 token 的 loss 平均计算的。

所以导致后面的推理结果出现了问题：两者同时采用 cot 推理接口的方法，结果 label-only 的 QKW 指标高于 cot 训练的 QWK 值。

下面是采取宽松统计方法得到的 CC 和 LC 在不同任务不同指标的结果。
